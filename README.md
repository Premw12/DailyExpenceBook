Daily Expense Tracker

Status: Work In Progress — Project is still under active development.

About
A Java web application to track daily expenses — manage shared expenses with friends and personal income/expense transactions with a secure login system.

Tech Stack
Backend: Java Servlets, JDBC
Frontend: JSP, HTML, CSS
Database: MySQL
Server: Apache Tomcat 9
Architecture: MVC Pattern
Features
✅ Login / Logout with Session Management
✅ Friends Module — Add, Edit, Delete friends
✅ Friend Expense Tracking — Get / Gave transactions
✅ Self Module — Personal Income & Expense tracking
✅ Dashboard with real-time balance summary
🔄 Register Page (coming soon)
🔄 Password Encryption (coming soon)
🔄 Monthly Reports & Charts (coming soon)
🔄 Export to PDF / Excel (coming soon)
How To Run
Import project into Eclipse as Dynamic Web Project
Set up MySQL and run the database schema
Update DB credentials in MyConnection.java
Deploy on Apache Tomcat 9
Open http://localhost:8082/DailyExpence
